## Phase 1e + 1f hardening pass (post adversarial review)

Adversarial review of the children backend surfaced 12 confirmed findings. All 5 high-severity findings fixed inline before commit; the test coverage gaps deferred. Summary:

- **usePinReset 404→401 oracle** fixed — no-such-child path now throws `InvalidPinResetCodeError` (401), same as bad-code path.
- **usePinReset timing oracle** fixed — every miss path performs a dummy argon2 verify so wall-clock duration is constant across (no-such-child / no-active-code / bad-code).
- **verifyPin TOCTOU on lockout counter** fixed — pre-increment inside `db.transaction()` before the slow argon2 verify so concurrent wrong-PIN bursts can't pin the counter below threshold.
- **PATCH backdoor on archivedAt / pinRequired** closed — `updateChildRequestSchema` drops both fields; archive flows only through dedicated endpoints (correct audit kind + (pinRequired, pinHash) dual invariant preserved).
- **archive / restore now idempotent** — second call preserves the original timestamp + skips the duplicate audit row.
- **Reset code DELIBERATELY bypasses PIN lockout** — it IS the recovery path; gating it on the lockout would brick the child. Documented in code + plan.
- **pin_locked audit kind** reserved for the transition only — attempts while already locked emit `pin_failure / reason: already_locked` so the audit dashboard counts lockouts (not taps).
- Plan wording updated: "5-in-15min" → "5-consecutive → 15-minute" to match implementation.

## What Phase 0 shipped

- `packages/shared/src/design/tokens.ts` — single source of truth. Two themes (`parent`, `child`), each with `palette / type / motion / radius / spacing / shadow / gradients` groups. Child theme adds `data-age="younger|older"` sub-theme via `AgeDelta`. Parent emits NO gradients (rule), child emits 5 named gradients restricted to TaskTile+TodayHero (rule).
- `packages/shared/src/design/tokens.test.ts` — 10 contract tests: theme parity, gradient counts, key shape, touch-target a11y. All pass.
- `scripts/build-tokens.ts` — generator. Emits `apps/web/src/styles/tokens.css` (gitignored) + `tailwind.theme.json`. Tied to `pnpm tokens:build` (also runs before `pnpm dev` / `pnpm build`).
- `apps/web/tailwind.config.ts` — reads generated theme JSON into Tailwind `theme.extend`. Components write `bg-bg text-text-muted min-h-touch rounded-2xl` etc. — all token-driven.
- `apps/web/src/styles/{index,globals}.css` — imports tokens.css; sets base body/heading/focus styles; honors `prefers-reduced-motion`.
- `apps/web/src/app/layouts/{ThemeBoundary,ParentShell,ChildShell}.tsx` — the ONLY component allowed to set `data-theme` / `data-age` (hard rule encoded in design-system skill).
- `apps/web/src/app/pages/DemoPage.tsx` — visual smoke route showing typography, buttons, status colors, gradient chips across both themes + both age bands. Will be removed in Phase 2 when real pages land.
